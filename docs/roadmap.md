# ArtNearby — статус фіч (roadmap)

Живий статус реалізації — оновлюється частіше за `about.md`, тому винесений в окремий файл. Контекст проєкту (ролі, user flow, модель даних) — див. [`about.md`](./about.md).

## Авторизація та профіль
| Функція | Статус |
|---|---|
| Реєстрація (фізична особа / компанія) | Готово, є баг: не перевіряється унікальність username/email → впаде з 500 при повторі (див. [`known-issues.md`](./known-issues.md)) |

## Геопошук найближчого магазину (головна фіча)
| Функція | Статус |
|---|---|
| Координати магазину (Location: довгота/широта) | Модель готова |
| Геолокація користувача (browser geolocation або по IP) | Не реалізовано |
| Розрахунок відстані до магазину з товаром | Не реалізовано |
| Список магазинів поруч, відсортований за відстанню | Не реалізовано |
| Побудова маршруту (карта + route) | Не реалізовано — MapTiler SDK вже підключено в шаблоні й ініціалізовано в `static/js/main.js`, але без міток і логіки |
